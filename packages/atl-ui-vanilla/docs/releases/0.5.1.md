# @atlanticrev/atl-ui-vanilla 0.5.1

Статус: кандидат к публикации 5 августа 2026 года в GitHub Packages.

## Главное

`0.5.1` — обратно совместимый patch-релиз с исправлением floating label у Select. Пакет сохраняет light DOM,
SSR-safe imports, независимые entry points и ноль runtime dependencies.

React-пакет и публичный API не изменялись.

## Select

- SVG notch теперь синхронно открывается при pointer focus, ещё до `mouseup` и открытия popup;
- floating label сразу занимает окончательную горизонтальную позицию и больше не пересекается с border;
- программный, клавиатурный и обычный click-flow Select сохраняют прежнее поведение;
- кроссбраузерная Playwright-регрессия проверяет удержание pointer focus в Chromium, Firefox и WebKit.
