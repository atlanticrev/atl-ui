# @atlanticrev/atl-ui-vanilla 0.6.0

Статус: кандидат к публикации 6 августа 2026 года в GitHub Packages.

## Главное

`0.6.0` добавляет content-backed Skeleton Host со стабильной геометрией, наследованием radius и плавным
fade-out. Пакет сохраняет light DOM, SSR-safe imports, независимые entry points и ноль runtime dependencies.

React-пакет не изменялся: новый контракт добавлен в vanilla package под подтверждённую потребность приложения
`social-video-posting`.

## Skeleton Host

- `.alt-skeleton-host` использует реальный authored content как источник размеров;
- `.alt-skeleton-host__content` остаётся в layout, но получает `aria-hidden` и `inert` во время loading;
- `setAltSkeletonHostLoading` доступен из root и `@atlanticrev/atl-ui-vanilla/skeleton`;
- overlay наследует вычисленный `border-radius` host;
- фон, highlight, shimmer, fade и overlay z-index настраиваются `--alt-skeleton-*` variables;
- ready content показывается сразу под 180 ms fade-out без изменения box geometry;
- `prefers-reduced-motion: reduce` отключает shimmer и fade;
- существующие `.alt-skeleton` и `.alt-skeleton-wrapper` остаются обратно совместимыми.

Полный контракт описан в [`../skeleton.md`](../skeleton.md).

## Проверка

Release candidate проверяется командами:

```bash
npm run verify:vanilla
npm run verify:vanilla:consumer
npm run demo:build --workspace @atlanticrev/atl-ui-vanilla
```

Unit tests покрывают state и invalid markup. Playwright проверяет geometry, inherited radius, focus isolation,
fade-out и reduced motion в Chromium, Firefox и WebKit.
