# @atlanticrev/atl-ui-vanilla 0.3.0

Статус: кандидат подготовлен к публикации в GitHub Packages.

## Главное

`0.3.0` добавляет единый `<alt-drawer>` для боковых Drawer и верхних или нижних Sheet. Это minor release:
появился новый публичный entry point, но существующие контракты остаются обратно совместимыми. Vanilla-пакет
по-прежнему использует light DOM, browser APIs и не имеет runtime dependencies.

## Drawer и Sheet

- `placement="left"` и `placement="right"` создают боковые Drawer;
- `placement="top"` и `placement="bottom"` создают полноширинные Sheet;
- native `<dialog>.showModal()` помещает компонент и backdrop в top layer;
- Escape, backdrop, программное закрытие и authored close actions используют единый lifecycle;
- после закрытия фокус возвращается на открывший Drawer элемент;
- swipe-to-dismiss поддерживает четыре направления, threshold и velocity, не конфликтует со скроллом Sheet;
- открытие, закрытие и snap-back анимируются плавно, а `prefers-reduced-motion` отключает движение;
- Popup, Select и Autocomplete внутри Drawer остаются поверх modal благодаря общему overlay contract.

Точечное подключение:

```ts
import '@atlanticrev/atl-ui-vanilla/default.css';
import { defineAltDrawer } from '@atlanticrev/atl-ui-vanilla/drawer';

defineAltDrawer();
```

Полный API, события, CSS tokens и touch-контракт описаны в [`../drawer.md`](../drawer.md).

## Общая инфраструктура

Dialog и Drawer используют общий native-modal lifecycle. Drawer и мобильный Date Range Picker используют
общий swipe-dismiss механизм, включая защиту от случайного compatibility click после touch-жеста. Это
устраняет две параллельные реализации при сохранении визуального и тактильного поведения.

## Публичная поверхность и проверка

- добавлен entry point `@atlanticrev/atl-ui-vanilla/drawer`;
- `define-all` регистрирует `<alt-drawer>` явно вместе с остальными элементами;
- export map содержит 26 JavaScript entry points и три CSS entry points;
- demo показывает Drawer и Sheet как отдельные продуктовые варианты;
- SSR-safe imports, tree shaking, focus, accessibility, вложенные overlays, desktop motion и touch gestures
  покрыты unit- и browser-тестами в Chromium, Firefox и WebKit.

Перед публикацией release commit должен пройти:

```bash
npm run verify:vanilla
npm run verify:vanilla:consumer
npm run demo:build --workspace @atlanticrev/atl-ui-vanilla
```
