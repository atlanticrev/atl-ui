# @atlanticrev/atl-ui-vanilla 0.6.1

Статус: patch-релиз 7 августа 2026 года в GitHub Packages.

## Skeleton visual consistency

- atomic `.alt-skeleton` без специального shape теперь использует системный `--alt-radius-sm` вместо нулевого
  radius;
- `line`, `circle`, `overlay` и пользовательский `--alt-skeleton-radius` сохраняют свои контракты;
- shimmer анимирует позицию gradient background, не перемещая overlay box через `transform`;
- fade-out больше не рисует shimmer за границами host после восстановления обычного `overflow` готового контента;
- Chromium, Firefox и WebKit покрыты регрессиями для default radius и bounded fade-out.

Публичные JavaScript exports и zero-runtime-dependency контракт не изменились.
