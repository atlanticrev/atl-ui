# @atlanticrev/atl-ui-vanilla 0.4.0

Статус: кандидат к публикации 24 июля 2026 года в GitHub Packages.

## Главное

`0.4.0` — обратно совместимый minor-релиз с новым самостоятельным многострочным form control
`<alt-textarea>`. Пакет сохраняет light DOM, SSR-safe imports, независимые entry points, browser-native form
semantics и ноль runtime dependencies.

React-пакет не изменялся: Textarea добавлен только в `@atlanticrev/atl-ui-vanilla` под подтверждённую
потребность приложения `social-video-posting`.

## Textarea

- добавлен точечный entry point `@atlanticrev/atl-ui-vanilla/textarea`;
- публичные exports включают `defineAltTextarea`, `createAltTextareaElementClass`,
  `AltTextareaElementApi`, event detail и size/status types;
- `<alt-textarea>` держит настоящий `<textarea>` в owned light DOM;
- label всегда остаётся в настоящем SVG notch и не перемещается при focus, value или placeholder;
- focus использует общий notched field contract без изменения размеров компонента;
- native field обслуживает `FormData`, external form ownership, reset, required/length validation,
  disabled, readonly, selection и autofill;
- `alt-input` и `alt-change` передают `{ value }`;
- character counter не вводит скрытый `max-length`: без ограничения он показывает только текущую длину;
- вертикальный native resize автоматически пересчитывает SVG outline через `ResizeObserver`;
- matching server light DOM и pre-upgrade property assignments сохраняются.

Полный контракт, атрибуты, properties, события и CSS tokens описаны в
[`../textarea.md`](../textarea.md).

## Публичный пакет и каталог

- Textarea добавлен в root exports, `define-all`, export map, сборочные entry points и общую тему;
- каталог содержит 34 поддерживаемые позиции;
- story покрывает основной сценарий, semantic states, disabled/readonly, counter, description и narrow
  content;
- consumer gate устанавливает tarball в чистый Vite-проект и подтверждает, что Textarea entry point не
  подтягивает реализации Input и Calendar.

## Проверка

Release candidate проверяется командами:

```bash
npm run verify:vanilla
npm run verify:vanilla:consumer
npm run demo:build --workspace @atlanticrev/atl-ui-vanilla
```

Unit/DOM-набор содержит 204 теста. Browser-набор содержит 141 выполненный тест в Chromium, Firefox и WebKit
и общий WCAG A/AA audit; ещё шесть touch-only сценариев ожидаемо пропускаются вне Chromium.
