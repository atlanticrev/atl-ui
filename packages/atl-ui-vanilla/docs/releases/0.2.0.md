# @atlanticrev/atl-ui-vanilla 0.2.0

Статус: опубликован 22 июля 2026 года в GitHub Packages. Версия `0.2.0` отмечена как latest; release tag
`atl-ui-vanilla-v0.2.0` указывает на проверенный commit `a0e07f8`.

## Главное

`0.2.0` завершает массовый перенос vanilla-компонентов и расширяет каталог до 32 поддерживаемых позиций:
20 managed/behavioral Web Components и 12 native CSS recipes. Пакет по-прежнему не имеет runtime
dependencies, использует light DOM и не требует React или другого renderer.

## Новый публичный API

После `0.1.0` добавлены шесть точечных entry points:

- `@atlanticrev/atl-ui-vanilla/calendar` — day/month/year views, single/range selection и presets;
- `@atlanticrev/atl-ui-vanilla/date-picker` — `<alt-date-picker>` и `<alt-date-range-picker>`;
- `@atlanticrev/atl-ui-vanilla/collapse` — доступное раскрытие authored content;
- `@atlanticrev/atl-ui-vanilla/menu` — клавиатурное меню с typeahead;
- `@atlanticrev/atl-ui-vanilla/pagination` — страницы, boundary items и ellipsis;
- `@atlanticrev/atl-ui-vanilla/search` — search field с native form events и SVG actions.

Полный export map теперь содержит 25 JavaScript entry points и три CSS entry points. Актуальная таблица
компонентов, custom elements и imports находится в [`../public-api.md`](../public-api.md).

## Overlays и компоненты

- Popup, Select, Autocomplete, Dropdown, Menu, Tooltip и date pickers используют общий top-layer overlay
  contract. Anchored overlays выходят за границы clipping containers и сохраняют fallback без CSS Anchor
  Positioning.
- Modal Dialog сохраняет native `<dialog>` semantics, focus containment и focus restore.
- Calendar и оба picker поддерживают day/month/year views, keyboard navigation и presets на общем Chip
  recipe; range picker на мобильном экране становится full-width bottom sheet.
- Input, Select, Autocomplete, Search и date picker используют согласованный focus contract без сдвига
  содержимого; floating label меняет цвет, но не толщину.
- Внутренние действия переиспользуют Button recipes и tree-shakeable SVG icons вместо текстовых символов.
- Alert по умолчанию занимает ширину содержимого, а Table, Chip, File Upload и Toast устойчивы к длинному
  контенту.

## Надёжность и delivery

- Добавлен полный GitHub Actions CI с ежедневным запуском в `01:30 UTC` и возможностью ручного запуска.
- Clean-consumer gate собирает tarball, устанавливает его в пустой проект и проверяет все JS/CSS imports,
  SSR safety, отсутствие auto-registration и runtime dependencies, а также Input-only tree shaking.
- Browser suite содержит 111 сценариев для Chromium, Firefox и WebKit, включая accessibility, keyboard,
  overlays, focus, layout и visual regressions.
- Pre-commit pipeline последовательно запускает Biome fixes/formatting и `atl-formatter`.
- Development runtime зафиксирован на Node 24 LTS; опубликованный пакет сохраняет `node >=18.18.0`.

## Обновление с 0.1.0

Намеренных breaking changes в существующих entry points нет. Рекомендуемый production-путь — заменить
широкую регистрацию через `define-all` точечными импортами используемых компонентов:

```ts
import '@atlanticrev/atl-ui-vanilla/default.css';
import { defineAltDateRangePicker } from '@atlanticrev/atl-ui-vanilla/date-picker';
import { defineAltInput } from '@atlanticrev/atl-ui-vanilla/input';

defineAltDateRangePicker();
defineAltInput();
```

Перед release commit/tag должны пройти:

```bash
npm run verify:vanilla
npm run verify:vanilla:consumer
```

После merge в `main` публикация выполняется вручную с personal access token classic:

```bash
npm run publish:vanilla
```

Команда проверяет release state, запускает оба gate и только после этого публикует пакет. Автоматическая
публикация по тегу отключена; тег `atl-ui-vanilla-v0.2.0` создаётся после успешной публикации. Полная
инструкция находится в [`releasing.md`](../releasing.md).
