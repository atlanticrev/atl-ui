# @atlanticrev/atl-ui-vanilla 0.5.0

Статус: кандидат к публикации 26 июля 2026 года в GitHub Packages.

## Главное

`0.5.0` — обратно совместимый minor-релиз с публичным pinning API для Table. Пакет сохраняет light DOM,
SSR-safe imports, независимые entry points и ноль runtime dependencies.

React-пакет не изменялся: Table pinning добавлен только в `@atlanticrev/atl-ui-vanilla` под подтверждённую
потребность приложения `social-video-posting`.

## Table pinning

- `AltTableColumn.fixed` принимает `'left'` или `'right'`;
- новый публичный тип `AltTableColumnFixed` экспортируется из root и точечного Table entry point;
- одновременно поддерживаются несколько закреплённых колонок с обеих сторон;
- смещения рассчитываются по фактической ширине заголовков, а `ResizeObserver` пересчитывает их при resize;
- закреплённые header и body cells получают непрозрачный фон и разделитель над прокручиваемыми ячейками;
- удаление `fixed` очищает служебные атрибуты и inline offset без пересоздания keyed cells.

Полный контракт описан в [`../content-overflow.md`](../content-overflow.md).

## Проверка

Release candidate проверяется командами:

```bash
npm run verify:vanilla
npm run verify:vanilla:consumer
npm run demo:build --workspace @atlanticrev/atl-ui-vanilla
```

DOM regression покрывает offsets, обе стороны и очистку состояния. Playwright проверяет реальную геометрию
нескольких закреплённых колонок в Chromium, Firefox и WebKit.
