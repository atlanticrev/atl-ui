# @atlanticrev/atl-ui-vanilla 0.3.1

Статус: опубликован 23 июля 2026 года в GitHub Packages. Версия `0.3.1` отмечена как latest; release tag
`atl-ui-vanilla-v0.3.1` указывает на проверенный commit `ec42e97`.

## Главное

`0.3.1` — обратно совместимый patch-релиз overlay-инфраструктуры и визуальных исправлений. Публичные
entry points, custom elements, события и атрибуты не менялись. Пакет по-прежнему использует light DOM,
browser APIs и не имеет runtime dependencies.

## Modal, Drawer и мобильные Sheet

- Dialog получил плавную 250 ms анимацию открытия и закрытия вместе с backdrop;
- `prefers-reduced-motion` отключает modal-анимацию;
- общий reference-counted scroll-lock используется Dialog, Drawer и мобильными календарными Sheet;
- scroll-lock блокирует реальный `document.scrollingElement`, сохраняя sticky header и sidebar приложения;
- backdrop следует за динамической высотой Android viewport через `100dvh`;
- вертикальный touch перехватывается до активации swipe, поэтому snap Sheet не запускает scroll страницы;
- scroll chaining отключён внутри Drawer и календарных Sheet;
- исходные inline-стили и фокус восстанавливаются после закрытия.

## Визуальные исправления

- Collapse больше не получает лишнюю верхнюю линию из demo-стилей;
- ширина Collapse остаётся стабильной при открытии длинного содержимого;
- Tooltip переопределяет browser `overflow: auto` и не показывает лишний scrollbar;
- Popup использует одну рамку и стандартный `.alt-popup__content` для authored content.

## Проверка

Release candidate проверяется командами:

```bash
npm run verify:vanilla
npm run verify:vanilla:consumer
npm run demo:build --workspace @atlanticrev/atl-ui-vanilla
```

Browser-набор покрывает Chromium, Firefox и WebKit; Android-specific touch behavior дополнительно
проверяется в Chromium с touch emulation и вручную в Google Chrome.
