# @atlanticrev/atl-ui-vanilla 0.7.0

Статус: minor-релиз 13 августа 2026 года в GitHub Packages.

## Table sizing

- `<alt-table>` автоматически вычисляет минимальную ширину из `width` и `minWidth` описаний колонок;
- колонки без явной ширины используют настраиваемый fallback `--alt-table-default-column-width`;
- `--alt-table-min-width` сохранён как явный consumer override;
- fixed columns используют те же размеры при расчёте ширины и pinning offsets.

## Collapse motion

- `<alt-collapse>` плавно открывает и закрывает authored `<details>` без дополнительных content wrappers;
- режим `single` анимирует как закрытие предыдущего item, так и открытие следующего;
- `prefers-reduced-motion: reduce` отключает переходы.

## Tooltip content

- публичный `text` API отделяет содержимое `<alt-tooltip>` от нативного `title`;
- legacy `title` автоматически мигрируется в `text` и удаляется, поэтому браузерный tooltip не дублирует
  компонентный;
- длинный текст переносится внутри ограниченной ширины и больше не наследует `white-space: nowrap` от trigger.

Цвет floating label в focus-состоянии Input, Select и Autocomplete подтверждён общей browser-регрессией в
light и dark themes. Пакет сохраняет zero-runtime-dependency и SSR-safe контракты.
